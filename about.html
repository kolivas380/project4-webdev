Tools and Frameworks

  1. Vue is a frontend Javascript framework that makes it quiick and efficient to develop single page web applications like this one. Vue allowed us to bind data to our HTML template and create functions in JS to provide the interactive user experience and dynamic processing.
  2. Node.js is what we used to develop our backend. Javascript runs outsie the browser, meaning it reads our database from within our local machine where we created the St. Paul Crime API.
  3. Express.js is built on top of Node.js adn this allowed us to create our server quickly so that Vue can display all of the data from the API. It handles the HTTP requests and sends the responses. Here is where we defined the specific endpoints that we called in the UI.
  4. Visual Studio Code is where we wrote our code and organized our files. We used the terminal to run the local host as well.
